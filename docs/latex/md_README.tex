{\bfseries{VSTOS}} — это легковесная 32-\/битная операционная система с монолитным ядром, написанная на C++ и ассемблере x86. Проект создан как образовательная площадка для изучения низкоуровневой разработки и как готовый шаблон (boilerplate) для тех, кто хочет начать свой путь в создании OS.\hypertarget{md_README_autotoc_md1}{}\doxysection{\texorpdfstring{Основные возможности}{Основные возможности}}\label{md_README_autotoc_md1}

\begin{DoxyItemize}
\item {\bfseries{Собственное Ядро\+:}} Написано на C++ с использованием {\ttfamily -\/ffreestanding}.
\item {\bfseries{VGA Драйвер\+:}} Полноценный вывод текста на экран, поддержка цветов, скроллинг и управление аппаратным курсором.
\item {\bfseries{Драйвер клавиатуры\+:}} Обработка скан-\/кодов через порты ввода-\/вывода ({\ttfamily 0x60}, {\ttfamily 0x64}).
\item {\bfseries{Интерактивный Shell\+:}} Поддержка команд ({\ttfamily help}, {\ttfamily about}, {\ttfamily clear}, {\ttfamily ascii}).
\item {\bfseries{Управление питанием\+:}} Команды перезагрузки ({\ttfamily reboot}) и программного выключения для QEMU.
\item {\bfseries{Hardware Interaction\+:}} Прямое управление светодиодами клавиатуры (Caps/\+Num/\+Scroll Lock).
\end{DoxyItemize}\hypertarget{md_README_autotoc_md2}{}\doxysection{\texorpdfstring{Технологический стек}{Технологический стек}}\label{md_README_autotoc_md2}

\begin{DoxyItemize}
\item {\bfseries{Языки\+:}} C++ (Kernel), Assembly x86 (Bootloader).
\item {\bfseries{Загрузчик\+:}} Multiboot-\/compliant (GRUB).
\item {\bfseries{Инструменты\+:}} GCC (g++), NASM, LD (Linker).
\item {\bfseries{Среда тестирования\+:}} QEMU / Bochs.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md3}{}\doxysection{\texorpdfstring{Как скомпилировать и запустить}{Как скомпилировать и запустить}}\label{md_README_autotoc_md3}

{\bfseries{Проблема с обработкой прерываний и вводом\+:}} Одной из главных сложностей была реализация корректного ввода с клавиатуры. В начале разработки при нажатии одной клавиши символ выводился бесконечно или система зависала. {\bfseries{Решение\+:}} Я изучил работу контроллера клавиатуры 8042 и реализовал проверку статусного регистра порта {\ttfamily 0x64} (проверка бита {\ttfamily 0} перед чтением данных из {\ttfamily 0x60}). Также пришлось вручную реализовать таблицу маппинга скан-\/кодов в символы ASCII, что дало понимание того, как аппаратура общается с драйвером.\hypertarget{md_README_autotoc_md8}{}\doxysection{\texorpdfstring{Планы на будущее}{Планы на будущее}}\label{md_README_autotoc_md8}

\item \mbox{[} \mbox{]} Поддержка динамической памяти (Memory Allocator).
